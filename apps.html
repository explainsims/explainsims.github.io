My Apps

Every app, site, repo and data store in one list, so you can decide what happens to each.

This page is only a checklist. Ticking a box doesn't change, delete or move anything. Your ticks and notes are saved in this browser only. Use Export to back them up or move them to another device.

My Apps Guide

What this is

A list of everything found in your Google Cloud projects and GitHub accounts on 24 September 2026: Cloud Run apps, repos, explainsims.com pages, stored data and cloud projects.

Descriptions for private repos are best guesses from the app name.

Checkboxes

Keep — you still want it. Retire app — take the running app down. Delete data — remove its stored data.

Archive repo / Make private — GitHub housekeeping. Move to ssis-apps — belongs with school apps. Needs work — something to fix. Done — decision carried out; the row fades.

Nothing happens when you tick a box. It's a record of your decisions only.

Pills

AI — the app calls a paid AI service. Public repo — anyone can read its code on GitHub. Important — you flagged it as important.

Links

explainsims.com/… is the app's address on your domain. Direct link (run.app) goes straight to Google Cloud and asks for your Google sign-in.

If an explainsims.com link doesn't load, use the direct link.

Search and filters

Search matches names, descriptions and repo names. Filter by group, or show only items with no boxes ticked yet to see what's left to decide.

Saving and backup

Ticks and notes save automatically in this browser. Export downloads them as a file; Import loads that file on another browser or device. Clearing site data erases them, so export now and then.
